FloodGuard

Vehicle network security

A real-time intrusion detection system for the CAN bus, the network cars use to send commands between modules. It watches packet frequencies, spots traffic that doesn't fit normal patterns, and shuts down flooding attacks before they drown out critical messages.

  • Monitors per-ID packet frequency in Python to flag anomalous traffic in real time
  • Packet-filtering logic detects and suppresses simulated CAN flooding attacks
  • Cross-platform Windows and Ubuntu simulation environment for modeling traffic and running attack scenarios

ProtectsIgnition commands stay deliverable even while the bus is being flooded.

  • Python
  • CAN bus
  • IDS
  • Ubuntu
  • Windows

Hardware security
